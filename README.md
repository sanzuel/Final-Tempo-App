# Drummer Pro Songs BPM - OFFLINE APK - Personal App

OFFLINE VERSION - No internet needed. Songs saved in phone (localStorage), metronome works offline.
Approved version, no design changes.
- Top spacing fixed with safe-area
- Songs 3-dot: Edit / Remove works
- Setlist Set A 3-dot: Remove works (Setlist only), long-press = drag
- Metronome 50% boost, Beat 1 louder

How to build OFFLINE APK for NEW Repo:
1. Create NEW repo, upload ALL files in this zip (extract first)
2. NO need to edit any URL - loads from inside APK (file:///android_asset/index.html)
3. Actions > Build APK - OFFLINE > Run > download app-debug-apk-OFFLINE
4. Install on phone - works in Airplane Mode / no WiFi / no data
Test: Airplane Mode ON, open Drummer Pro, add song, play metronome - should work.
